التحليل داخل المتصفح فقط. لا fetch ولا رفع ملفات ولا API ولا localStorage. الحد الأقصى 256 KiB و2,500 سطر. بعد نجاح التحليل يُمسح النص الخام من مربع الإدخال وتبقى النسخة المنقّحة في ذاكرة الصفحة حتى تمسحها أو تغلقها.
